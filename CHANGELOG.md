# Changelog

## 3.0.0 — 2026-10-13

- First public, network-neutral desktop and Android release.
- Custom network names, SSID and hostname templates, and local profile storage without passwords.
- Manual management IP plus configurable CIDR, gateway and DNS.
- Optional IP-number generation; independent large device numbers and VLAN IDs.
- LAN default; WAN bridging, Watchcat removal and client isolation opt-in.
- Synthetic demo fixture, automated regression tests and build documentation.
